# structured config

Use the format parser or validator when available. Preserve comments and key ordering where meaningful. Check schema, types and interpolation behavior. Make focused changes and validate the consuming application. Avoid textual replacements that can affect similar keys in unrelated sections.

## Execution discipline

Follow the user's current scope and AgentScope permissions. Load only supporting references relevant to this task. Use actual tool evidence, stop on an unexplained failure, and report what was verified and what remains uncertain. Never fabricate outputs or bypass denied actions.
