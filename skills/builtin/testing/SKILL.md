# testing

Choose observable behavior at stable boundaries. Include a normal path, meaningful failure and relevant authorization edge. Use deterministic fixtures. Mock remote services at the transport boundary without mocking the implementation under test. Run the smallest relevant test set before the broader suite.

## Execution discipline

Follow the user's current scope and AgentScope permissions. Load only supporting references relevant to this task. Use actual tool evidence, stop on an unexplained failure, and report what was verified and what remains uncertain. Never fabricate outputs or bypass denied actions.
