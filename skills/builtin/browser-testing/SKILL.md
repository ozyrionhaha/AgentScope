# browser testing

Start the app and retain its terminal session. Navigate to the actual URL, inspect visible elements and console errors, then exercise the requested user flow. Include loading, error and empty states. Capture evidence after the final change. Never claim visual verification from a successful build alone.

## Execution discipline

Follow the user's current scope and AgentScope permissions. Load only supporting references relevant to this task. Use actual tool evidence, stop on an unexplained failure, and report what was verified and what remains uncertain. Never fabricate outputs or bypass denied actions.
