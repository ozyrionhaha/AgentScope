# environment

Inspect documented variable names and validation code. Never print secret values or commit real credentials. Maintain a safe example file. Distinguish server-only and browser-exposed variables. Fail startup clearly for missing required settings and avoid silently substituting production defaults.

## Execution discipline

Follow the user's current scope and AgentScope permissions. Load only supporting references relevant to this task. Use actual tool evidence, stop on an unexplained failure, and report what was verified and what remains uncertain. Never fabricate outputs or bypass denied actions.
