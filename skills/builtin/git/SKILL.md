# git

Read status before changing anything. Preserve staged and unstaged user changes. Resolve conflicts by understanding both intents and verifying the merged result. Stage named files, inspect staged diff, then commit only when authorized. Never reset hard, force push or delete branches without explicit permission.

## Execution discipline

Follow the user's current scope and AgentScope permissions. Load only supporting references relevant to this task. Use actual tool evidence, stop on an unexplained failure, and report what was verified and what remains uncertain. Never fabricate outputs or bypass denied actions.
