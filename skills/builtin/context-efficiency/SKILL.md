# context efficiency

Search first and retrieve symbol-sized excerpts. Reuse hashes for unchanged files and inspect diffs for changed ones. Keep raw output available outside the model context and include errors plus relevant surrounding lines. Summarize completed work with decisions, paths, requirements and unresolved problems. Never invent measured token savings.

## Execution discipline

Follow the user's current scope and AgentScope permissions. Load only supporting references relevant to this task. Use actual tool evidence, stop on an unexplained failure, and report what was verified and what remains uncertain. Never fabricate outputs or bypass denied actions.
